# ⛳ ゴルフ チーム戦スコア計算

ゴルフのチーム戦（コンペ）の勝敗を、カスタムルールで計算するローカル Web アプリです。
ブラウザで動作し、通信は一切行いません。データは端末内（localStorage）にのみ保存されます。

## 特徴

- **チーム数・人数とも可変** — 何チームでも、1チーム何人でも登録できます。
- **合計打数だけ入力** — プレイヤーごとに「グロス（合計打数）」を入れるだけ。
- **ネットの入力方法を切り替え可能** — 次の2方式をボタンで切り替えられます。
  - **ハンディから計算**：ハンディを入力し、ネット＝グロス−ハンディ を自動算出。
  - **ネットを直接入力**：計算済みのネットスコアをそのまま入力。
- **カスタム勝敗ルール** — 全プレイヤーの個人順位（グロス・ネット）をチーム単位で合計し、総合優勝を決めます（下記）。
- **個人順位の表示** — 集計結果に、各プレイヤーのグロス順位・ネット順位に加え、チーム戦と同じ基準（グロス順位＋ネット順位の合算）で付けた個人順位を一覧表示します。
- **共有リンク** — 「共有リンクを作成」で、今の順位結果を URL に埋め込んだリンクを生成。相手はリンクを開くだけで結果を閲覧できます（サーバー不要）。
- **オフライン動作・自動保存** — 通信不要。入力は自動で端末に保存されます。
- **JSON 書き出し／読み込み** — データのバックアップ・共有ができます。

## 勝敗ルール（カスタム）

まず**全プレイヤーを1つの母集団**として個人順位を付け、それをチーム単位で合計します。

1. **グロス個人順位** … 全プレイヤーをグロスの少ない順に並べた個人順位（同スコアは同順位）
2. **ネット個人順位** … 全プレイヤーをネット（＝グロス−ハンディ、または直接入力値）の少ない順に並べた個人順位
3. **グロス順位合計** = そのチームに所属するプレイヤーのグロス個人順位の合計
4. **ネット順位合計** = そのチームに所属するプレイヤーのネット個人順位の合計
5. **合算** = グロス順位合計 ＋ ネット順位合計

**合算が最小のチームが総合優勝**です。合算が同じ場合は、ネット順位合計が少ないチームを上位とします。

> 例：3チーム×各3人の場合、全9人にグロス順位（1〜9位）とネット順位（1〜9位）を付け、各チームの所属選手の順位を足し合わせます。グロス順位合計とネット順位合計をさらに足した「合算」が最も小さいチームが優勝です。
>
> ※ チームのグロス合計打数・ネット合計打数で順位を決めるのではなく、**あくまで個人順位をチームで合計**する方式です。

## 公開URL（GitHub Pages）

このリポジトリを GitHub Pages で公開すると、次の URL でブラウザから直接利用できます。

**https://masaofuruta.github.io/golf-team-score/**

### 公開手順（初回のみ）

1. この変更を `main` ブランチに反映（マージ）します。
2. リポジトリの **Settings → Pages** を開きます。
3. **Build and deployment** の **Source** を「Deploy from a branch」にします。
4. **Branch** を `main` / `/(root)` に設定して **Save** します。
5. 数十秒〜数分後、上記 URL で公開されます。

> ルート直下の `index.html` がそのまま入口になります。`.nojekyll` を置いているため、Jekyll による変換は行われず、ファイルはそのまま配信されます。

## 使い方

1. 上記の公開URL、または手元の `index.html` をブラウザで開きます（ローカルはダブルクリックでOK。インストール不要）。
2. 「大会情報」に大会名・日付・コースを入力します（任意）。
3. 「ネットの入力方法」を選びます（**ハンディから計算** / **ネットを直接入力**）。
4. 「＋ チームを追加」でチームを作り、各チームに「＋ プレイヤーを追加」でメンバーを登録します。
5. 各プレイヤーのスコアを入力します。
   - ハンディから計算モード：**ハンディ** と **グロス** を入力（ネットは自動計算）。
   - ネット直接入力モード：**グロス** と **ネット** を入力。
6. 「集計結果」に総合順位・優勝チームが表示されます。

初めて触るときは「サンプルデータを入れる」で動作を確認できます。

## 結果を他の人に見せる（共有リンク）

「ツール」の **「🔗 共有リンクを作成」** を押すと、その時点の入力内容を URL 自体に埋め込んだ共有リンクが作られます（自動でクリップボードにコピー。うまくコピーできない場合は表示された URL を手動でコピー）。

- 相手はそのリンクを開くだけで、**同じ順位結果を閲覧**できます。専用のサーバーやログインは不要です。
- リンクを開いた画面は **閲覧用**として動作し、上部にその旨のバナーが出ます。閲覧側で数値を触っても**その人の端末には保存されません**（作成者のデータを壊しません）。閲覧側が「この内容を編集する」を押すと、自分の端末に保存して編集を始められます。
- 共有リンクは**作成時点のスナップショット**です。スコアを更新したら、リンクを作り直して共有してください。
- データは URL に含めているだけで、サーバーには送信していません。

## ファイル構成

```
.
├─ index.html   画面（HTML）
├─ styles.css   デザイン（CSS）
├─ app.js       計算ロジック・保存・UI（JavaScript）
├─ .nojekyll    GitHub Pages で Jekyll 変換を無効化
└─ README.md    このファイル
```

外部ライブラリやビルド環境は不要です。3ファイルだけで完結します。

## データについて

- 入力データはブラウザの **localStorage** に保存され、端末外に送信されません。
- 別の端末やブラウザに移す場合は「JSON書き出し」で保存し、移行先で「JSON読み込み」してください。
- 「全消去」で保存データを初期化できます。
