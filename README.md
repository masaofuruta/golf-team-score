# ⛳ ゴルフ チーム戦スコア計算

ゴルフのチーム戦（コンペ）の勝敗を、カスタムルールで計算するローカル Web アプリです。
ブラウザで動作し、通信は一切行いません。データは端末内（localStorage）にのみ保存されます。

## 特徴

- **チーム数・人数とも可変** — 何チームでも、1チーム何人でも登録できます。
- **合計打数だけ入力** — プレイヤーごとに「グロス（合計打数）」と「ハンディ」を入れるだけ。
- **ネットスコア自動計算** — ネット＝グロス−ハンディ を自動で算出します。
- **カスタム勝敗ルール** — グロス合計とネット合計の**両方**で順位を出し、合算して総合優勝を決めます（下記）。
- **オフライン動作・自動保存** — 通信不要。入力は自動で端末に保存されます。
- **JSON 書き出し／読み込み** — データのバックアップ・共有ができます。

## 勝敗ルール（カスタム）

各チームについて次を計算します。

1. **グロス合計** = チーム内プレイヤーのグロスの合計
2. **ネット合計** = チーム内プレイヤーのネット（＝グロス−ハンディ）の合計
3. **グロス順位** … グロス合計が少ない順の順位
4. **ネット順位** … ネット合計が少ない順の順位
5. **合算** = グロス順位 ＋ ネット順位

**合算が最小のチームが総合優勝**です。合算が同じ場合は、ネット合計が少ないチームを上位とします。

> 例：グロス順位1位・ネット順位2位のチームは合算「3」。グロス順位2位・ネット順位1位のチームも合算「3」で同点となり、ネット合計が少ない方が上位になります。

## 使い方

1. `index.html` をブラウザで開きます（ダブルクリックでOK。インストール不要）。
2. 「大会情報」に大会名・日付・コースを入力します（任意）。
3. 「＋ チームを追加」でチームを作り、各チームに「＋ プレイヤーを追加」でメンバーを登録します。
4. 各プレイヤーの **ハンディ** と **グロス** を入力します。ネットと各種順位は自動計算されます。
5. 「集計結果」に総合順位・優勝チームが表示されます。

初めて触るときは「サンプルデータを入れる」で動作を確認できます。

## ファイル構成

```
.
├─ index.html   画面（HTML）
├─ styles.css   デザイン（CSS）
├─ app.js       計算ロジック・保存・UI（JavaScript）
└─ README.md    このファイル
```

外部ライブラリやビルド環境は不要です。3ファイルだけで完結します。

## データについて

- 入力データはブラウザの **localStorage** に保存され、端末外に送信されません。
- 別の端末やブラウザに移す場合は「JSON書き出し」で保存し、移行先で「JSON読み込み」してください。
- 「全消去」で保存データを初期化できます。
